# House Price Prediction Using Simple Linear Regression

## Activity 2: Simple House Price Prediction

**Subject:** Supervised Learning: Regression  
**Unit:** Unit II  
**Activity:** 2 – Simple House Price Prediction  
**Algorithm:** Simple Linear Regression  
**Programming Language:** Python  
**Platform:** Google Colab  

---

## 1. Introduction

This project focuses on predicting house prices using Simple Linear Regression.

The California Housing Dataset is used to understand the relationship between median income and median house value.

The model learns from the training data and predicts house values for unseen testing data.

## 2. Objectives

- Understand the concept of supervised learning.
- Load and explore a housing dataset.
- Identify input and target variables.
- Perform exploratory data analysis.
- Split the dataset into training and testing sets.
- Build a Simple Linear Regression model.
- Generate house price predictions.
- Evaluate the model using regression metrics.

## 3. Dataset Information

**Dataset Name:** California Housing Dataset

**Dataset Source:** Scikit-learn

**Documentation:**  
https://scikit-learn.org/stable/datasets/real_world.html#california-housing-dataset

**Total Records:** 20,640

**Total Columns:** 9

**Input Feature:** MedInc (Median Income)

**Target Variable:** MedHouseVal (Median House Value)

**Target Unit:** $100,000

## 4. Tools and Technologies

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 5. Methodology

The following steps are performed:

1. Import Python libraries.
2. Load the California Housing Dataset.
3. Inspect the dataset structure.
4. Perform Exploratory Data Analysis.
5. Select input and target variables.
6. Split data into training and testing sets.
7. Train the Linear Regression model.
8. Generate predictions.
9. Evaluate model performance.
10. Visualize the prediction results.

## 6. Data Visualization

The following graphs are generated:

- Distribution of House Prices.
- Median Income vs House Price.
- Correlation Heatmap.
- Actual vs Predicted House Prices.
- Regression Line.
- Residual Plot.

## 7. Model Evaluation

The model is evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R-squared (R²) Score

These metrics help measure the accuracy and performance of the regression model.

## 8. Output

The model generates predicted house values using the testing dataset.

Prediction results are saved in:

`House_Price_Predictions.csv`

## 9. Conclusion

The Simple Linear Regression model was successfully implemented using the California Housing Dataset.

The relationship between median income and median house value was analyzed. The dataset was divided into training and testing sets, and the model was trained to predict house values.

The performance of the model was evaluated using MAE, MSE, RMSE and R² score.

This activity provided practical understanding of supervised learning and regression techniques.
